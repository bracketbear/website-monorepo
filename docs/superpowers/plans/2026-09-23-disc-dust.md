# Disc Dust Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A second pass on the disc toy: feeding reaches a gap in about a minute, the opening state has a carved lane, the display has headroom for density contrast, and 65,536 dust grains drift on the gas so the disc visibly rotates and gaps empty.

**Architecture:** The gas integrator is untouched. Feeding is a constants change checked on the production-size mirror. Dust is a `Particles` helper on the gas `PingPong`'s GL context: a float texture of `(ln r, φ, St, alive)` stepped once per gas substep by a fragment shader that samples the gas texture, and drawn as additive `gl.POINTS` after the display pass. A CPU twin in `grains.ts` is what the tests run. The reduce pass is chunked eight ways along each ring.

**Tech Stack:** TypeScript, WebGL2 (GLSL ES 3.00), PIXI v8 for the blit, vitest for the mirror, npm workspaces.

**Spec:** `docs/superpowers/specs/2026-09-23-disc-dust-design.md` (builds on `docs/superpowers/specs/2026-09-23-disc-design.md`).

## Global Constraints

- Units: `GM★ = 1`, `R_IN = 0.25`, `R_OUT = 2.0`, `STEP = 0.01`, wall clock `UNITS_PER_SECOND = 1.57`, at most 6 substeps a frame. Production grid `512 (φ) × 192 (ln r)`; texture x is `j` (φ), texture y is `i` (ln r); array index `k = i * nphi + j`.
- Gas state channels: `x = Σ`, `y = v_r`, `z = v_φ` (full), `w = mass eaten this frame`. Grain channels: `x = ln r`, `y = φ ∈ [0, 2π)`, `z = St`, `w = alive (1 or 0)`.
- New constants, exact: `SEED_Q = 1e-4`; `DEFAULT_PARAMS.accRate = 0.5`; `DEFAULT_PARAMS.sinkFloorCells = 2`; `accretionRate` control `0.05–2` step `0.05` default `0.5`; `dust` control `0–1` step `0.05` default `0.6`; `uKappa = 0.5 / Σ₀`; display emission gain `1.6`; `FLARE_TAU = 6`; `REDUCE_CHUNKS = 8`; `N_GRAINS = 65536`, `GRAIN_W = 256`; `ST_MIN = 0.02`, `ST_MAX = 0.2`, log-uniform; grains seeded uniform in `r ∈ [0.3, 1.9]`; default bodies `q = 1.5e-3` at `r = 0.6` and `q = SEED_Q` at `r = 1.3`; `PREROLL_STEPS = 6280` unchanged.
- The mirror in `grains.ts` and `GRAIN_STEP_FS` must implement the same sample and the same drift: hand-wrapped bilinear in `(i, j)`, `i` clamped, `j` wrapped; Σ floored at `D.floor` before dividing; drift clamped to `c_s = h / √r`.
- Grains never write into the gas. No sink for grains. Nothing respawns.
- Vitest runs from the repo root: `npx vitest run packages/flateralus-pixi-animations/src/disc`. The package's `dist` is what the lab serves: `npm run build --workspace=@bracketbear/flateralus-pixi-animations` before any browser check.
- Commit after every task; messages in the repo's voice (`feat(disc): …`, `fix(disc): …`, `docs(lab): …`), no trailing attribution unless the session reminder asks for it.
- This branch's worktree is `.claude/worktrees/disc-dust`, branch `worktree-disc-dust`, based on `disc`. Run everything from there.

## Review Focus

Inputs the spec implies but no task's tests exercise; each has a test added to its owning task below.

1. A grain sampled at a φ within one cell of the seam (`φ ≈ 0` or `≈ 2π`) must see the same gas as one just across it: the wrap in `sampleGas` must not clamp. (Task 5.)
2. A grain at the inner taper, where Σ sits at the floor two cells in, must not divide by zero or drift at more than the sound speed: the floor and the clamp both apply. (Task 5.)
3. A grain that crosses `R_IN` or `R_OUT` is dead and stays dead: a dead grain is not stepped, and `stepGrains` never revives one. (Task 5.)
4. The chunked reduce must sum to the unchunked total for every planet slot and the star column: the CPU summation loop indexes `k * REDUCE_CHUNKS + c`, not `k + c`. (Task 3, checked on screen against the mirror's force magnitude since the shader cannot run under vitest.)
5. `reseed` must reseed the grains as well as the gas, and with a different draw for Collapse A, B and C. (Task 6, checked on screen.)

- [ ] **Step 2: The shader**

Replace the body of `main()` in `REDUCE_FS`:

```glsl
    void main() {
      G = textureSize(uState, 0);
      int col = int(gl_FragCoord.x);
      int slot = col / ${REDUCE_CHUNKS};
      int chunk = col - slot * ${REDUCE_CHUNKS};
      int span = G.x / ${REDUCE_CHUNKS};
      int j0 = chunk * span, j1 = j0 + span;
      int i = int(gl_FragCoord.y);
      float r = rAt(i), A = areaAt(i);
      vec4 acc = vec4(0.0);
      if (slot < uPlanetN) {
        vec4 pl = uPlanet[slot];
        float eps = 0.6 * uH * pl.w;
        float eps2 = eps * eps;
        float rh = pl.w * pow(pl.z / 3.0, 1.0 / 3.0);
        float rs = max(0.5 * rh, uSinkFloor * r * uDphi) + 2.0 * r * uDphi;
        for (int j = j0; j < j1; j++) {
          vec4 c = S(i, j);
          float phi = (float(j) + 0.5) * uDphi;
          vec2 d = vec2(r * cos(phi), r * sin(phi)) - pl.xy;
          float d2 = dot(d, d);
          float d2e = d2 + eps2;
          acc.xy += (c.x * A) * d / (d2e * sqrt(d2e));
          if (d2 < rs * rs) acc.z += c.w * A;
        }
      } else if (slot == ${MAX_PLANETS}) {
        for (int j = j0; j < j1; j++) {
          vec4 c = S(i, j);
          acc.y += c.x * A;
          if (i == 0) acc.x += c.x * min(c.y, 0.0) * rfAt(0) * uDphi;
        }
      }
      fragColor = acc;
    }
```

- [ ] **Step 2: The helper**

Create `particles.ts`:

```ts
import { VERT } from './shader-harness';

/**
 * A set of particles on the GPU: an n-texel RGBA32F ping-pong pair, a
 * fragment shader that steps every particle, and a points draw that
 * reads them by gl_VertexID. Built on someone else's context — a
 * PingPong's — so the step can sample that context's field texture.
 * Float render targets are mandatory; `create` returns null without them
 * and the caller runs without particles.
 */
export interface ParticlesOptions {
  stepFrag: string;
  drawVert: string;
  drawFrag: string;
  stepUniforms: readonly string[];
  drawUniforms: readonly string[];
  /** Texture width; n must divide by it. Default 256. */
  width?: number;
}

type Locs = Record<string, WebGLUniformLocation | null>;

function compile(
  gl: WebGL2RenderingContext,
  type: number,
  src: string,
  tag: string
) {
  const sh = gl.createShader(type)!;
  gl.shaderSource(sh, src);
  gl.compileShader(sh);
  if (!gl.getShaderParameter(sh, gl.COMPILE_STATUS)) {
    console.error(`particles ${tag}:`, gl.getShaderInfoLog(sh));
    return null;
  }
  return sh;
}

function program(
  gl: WebGL2RenderingContext,
  vert: string,
  frag: string,
  tag: string
) {
  const vs = compile(gl, gl.VERTEX_SHADER, vert, tag);
  const fs = compile(gl, gl.FRAGMENT_SHADER, frag, tag);
  if (!vs || !fs) return null;
  const p = gl.createProgram()!;
  gl.attachShader(p, vs);
  gl.attachShader(p, fs);
  gl.linkProgram(p);
  if (!gl.getProgramParameter(p, gl.LINK_STATUS)) {
    console.error(`particles link ${tag}:`, gl.getProgramInfoLog(p));
    return null;
  }
  return p;
}

export class Particles {
  readonly gl: WebGL2RenderingContext;
  readonly n: number;
  readonly w: number;
  readonly h: number;

  private stepProg: WebGLProgram;
  private drawProg: WebGLProgram;
  private stepL: Locs = {};
  private drawL: Locs = {};
  private tex: (WebGLTexture | null)[] = [null, null];
  private fbo: (WebGLFramebuffer | null)[] = [null, null];
  private cur = 0;

  private constructor(
    gl: WebGL2RenderingContext,
    n: number,
    w: number,
    stepProg: WebGLProgram,
    drawProg: WebGLProgram
  ) {
    this.gl = gl;
    this.n = n;
    this.w = w;
    this.h = n / w;
    this.stepProg = stepProg;
    this.drawProg = drawProg;
  }

  static create(
    gl: WebGL2RenderingContext,
    n: number,
    o: ParticlesOptions
  ): Particles | null {
    const w = o.width ?? 256;
    if (n % w !== 0) return null;
    if (!gl.getExtension('EXT_color_buffer_float')) return null;
    const stepProg = program(gl, VERT, o.stepFrag, 'step');
    const drawProg = program(gl, o.drawVert, o.drawFrag, 'draw');
    if (!stepProg || !drawProg) return null;
    const ps = new Particles(gl, n, w, stepProg, drawProg);
    gl.useProgram(stepProg);
    for (const name of ['uParticles', 'uPW', ...o.stepUniforms])
      ps.stepL[name] = gl.getUniformLocation(stepProg, name);
    gl.useProgram(drawProg);
    for (const name of ['uParticles', 'uPW', ...o.drawUniforms])
      ps.drawL[name] = gl.getUniformLocation(drawProg, name);
    for (let i = 0; i < 2; i++) {
      const tx = gl.createTexture()!;
      gl.bindTexture(gl.TEXTURE_2D, tx);
      gl.texImage2D(
        gl.TEXTURE_2D,
        0,
        gl.RGBA32F,
        ps.w,
        ps.h,
        0,
        gl.RGBA,
        gl.FLOAT,
        null
      );
      gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MIN_FILTER, gl.NEAREST);
      gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MAG_FILTER, gl.NEAREST);
      gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_S, gl.CLAMP_TO_EDGE);
      gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_T, gl.CLAMP_TO_EDGE);
      const fb = gl.createFramebuffer()!;
      gl.bindFramebuffer(gl.FRAMEBUFFER, fb);
      gl.framebufferTexture2D(
        gl.FRAMEBUFFER,
        gl.COLOR_ATTACHMENT0,
        gl.TEXTURE_2D,
        tx,
        0
      );
      const ok =
        gl.checkFramebufferStatus(gl.FRAMEBUFFER) === gl.FRAMEBUFFER_COMPLETE;
      ps.tex[i] = tx;
      ps.fbo[i] = fb;
      if (!ok) {
        gl.bindFramebuffer(gl.FRAMEBUFFER, null);
        ps.destroy();
        return null;
      }
    }
    gl.bindFramebuffer(gl.FRAMEBUFFER, null);
    return ps;
  }

  /** Overwrite every particle; n * 4 floats. */
  init(data: Float32Array): void {
    const gl = this.gl;
    for (let i = 0; i < 2; i++) {
      gl.bindTexture(gl.TEXTURE_2D, this.tex[i]);
      gl.texImage2D(
        gl.TEXTURE_2D,
        0,
        gl.RGBA32F,
        this.w,
        this.h,
        0,
        gl.RGBA,
        gl.FLOAT,
        data
      );
    }
    this.cur = 0;
  }

  /** Step every particle once. The caller binds any other samplers on units ≥ 1. */
  step(setUniforms?: (gl: WebGL2RenderingContext, locs: Locs) => void): void {
    const gl = this.gl;
    const dst = 1 - this.cur;
    gl.bindFramebuffer(gl.FRAMEBUFFER, this.fbo[dst]);
    gl.viewport(0, 0, this.w, this.h);
    gl.useProgram(this.stepProg);
    gl.activeTexture(gl.TEXTURE0);
    gl.bindTexture(gl.TEXTURE_2D, this.tex[this.cur]);
    gl.uniform1i(this.stepL.uParticles!, 0);
    gl.uniform1i(this.stepL.uPW!, this.w);
    setUniforms?.(gl, this.stepL);
    gl.drawArrays(gl.TRIANGLES, 0, 3);
    this.cur = dst;
  }

  /** Add every particle to the canvas as a point. */
  draw(
    W: number,
    H: number,
    setUniforms?: (gl: WebGL2RenderingContext, locs: Locs) => void
  ): void {
    const gl = this.gl;
    gl.bindFramebuffer(gl.FRAMEBUFFER, null);
    gl.viewport(0, 0, W, H);
    gl.useProgram(this.drawProg);
    gl.activeTexture(gl.TEXTURE0);
    gl.bindTexture(gl.TEXTURE_2D, this.tex[this.cur]);
    gl.uniform1i(this.drawL.uParticles!, 0);
    gl.uniform1i(this.drawL.uPW!, this.w);
    setUniforms?.(gl, this.drawL);
    gl.enable(gl.BLEND);
    gl.blendFunc(gl.ONE, gl.ONE);
    gl.drawArrays(gl.POINTS, 0, this.n);
    gl.disable(gl.BLEND);
  }

  destroy(): void {
    const gl = this.gl;
    for (let i = 0; i < 2; i++) {
      if (this.tex[i]) gl.deleteTexture(this.tex[i]);
      if (this.fbo[i]) gl.deleteFramebuffer(this.fbo[i]);
      this.tex[i] = null;
      this.fbo[i] = null;
    }
    gl.deleteProgram(this.stepProg);
    gl.deleteProgram(this.drawProg);
  }
}
```

```ts
/**
 * Dust grains, on the CPU. The twin of `GRAIN_STEP_FS` in shaders.ts:
 * the same bilinear sample of the gas, the same terminal-velocity drift,
 * the same integration in (ln r, φ). Grains ride the gas and drift toward
 * pressure maxima; they do not act on the gas.
 */
import { R_IN, R_OUT, cs2, type Disc, type DiscParams } from './physics';

export const N_GRAINS = 65536;
export const GRAIN_W = 256;
/** Stokes numbers, log-uniform. 0.2 clears a lane edge in tens of seconds; 0.02 lingers for minutes. */
export const ST_MIN = 0.02;
export const ST_MAX = 0.2;
/** Grains are seeded uniform in r on this range: Σ ∝ 1/r makes that uniform in mass. */
const SEED_R_MIN = 0.3;
const SEED_R_MAX = 1.9;
const TAU = 2 * Math.PI;

/** A small seeded PRNG so Collapse A, B and C draw different dust. */
export function mulberry32(seed: number): () => number {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6d2b79f5) >>> 0;
    let t = a;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

export function seedGrains(n: number, rng: () => number): Float32Array {
  const g = new Float32Array(n * 4);
  const lnMin = Math.log(ST_MIN);
  const lnMax = Math.log(ST_MAX);
  for (let k = 0; k < n; k++) {
    const r = SEED_R_MIN + (SEED_R_MAX - SEED_R_MIN) * rng();
    g[k * 4] = Math.log(r);
    g[k * 4 + 1] = TAU * rng();
    g[k * 4 + 2] = Math.exp(lnMin + (lnMax - lnMin) * rng());
    g[k * 4 + 3] = 1;
  }
  return g;
}

/**
 * Bilinear in (i, j) with i clamped and j wrapped — the display shader's
 * sampleDisc, and the shader's gas(). φ may be outside [0, 2π).
 */
export function sampleGas(
  D: Disc,
  lnr: number,
  phi: number
): [number, number, number] {
  const { nr, nphi, dlnr, dphi, sig, vr, vp } = D;
  const fi = (lnr - Math.log(R_IN)) / dlnr - 0.5;
  const fj = phi / dphi - 0.5;
  const i0 = Math.floor(fi);
  const j0 = Math.floor(fj);
  const ti = fi - i0;
  const tj = fj - j0;
  const ia = Math.max(0, Math.min(nr - 1, i0));
  const ib = Math.max(0, Math.min(nr - 1, i0 + 1));
  const ja = ((j0 % nphi) + nphi) % nphi;
  const jb = (ja + 1) % nphi;
  const k00 = ia * nphi + ja;
  const k01 = ia * nphi + jb;
  const k10 = ib * nphi + ja;
  const k11 = ib * nphi + jb;
  const lerp = (a: Float32Array) => {
    const top = a[k00] + (a[k01] - a[k00]) * tj;
    const bot = a[k10] + (a[k11] - a[k10]) * tj;
    return top + (bot - top) * ti;
  };
  return [lerp(sig), lerp(vr), lerp(vp)];
}

/**
 * One grain, one step. Terminal-velocity drift: Δv = t_s ∇P / Σ with
 * t_s = St / Ω_K, clamped to the sound speed; then (ln r, φ) advance by
 * (v_gas + Δv) / r · dt, which makes a circular orbit exact at any step.
 */
function stepGrain(D: Disc, p: DiscParams, g: Float32Array, o: number): void {
  if (g[o + 3] === 0) return;
  const { dlnr, dphi, floor } = D;
  const h = p.h;
  const dt = p.dt;
  const lnr = g[o];
  const phi = g[o + 1];
  const st = g[o + 2];
  const r = Math.exp(lnr);
  const om = Math.pow(r, -1.5);
  const [s0, vr, vp] = sampleGas(D, lnr, phi);
  const sig = Math.max(s0, floor);
  const rp = Math.exp(lnr + dlnr);
  const rm = Math.exp(lnr - dlnr);
  const sp = Math.max(sampleGas(D, lnr + dlnr, phi)[0], floor);
  const sm = Math.max(sampleGas(D, lnr - dlnr, phi)[0], floor);
  const dPdr = (cs2(rp, h) * sp - cs2(rm, h) * sm) / (rp - rm);
  const jp = sampleGas(D, lnr, phi + dphi)[0];
  const jm = sampleGas(D, lnr, phi - dphi)[0];
  const dPdphi = (cs2(r, h) * (jp - jm)) / (2 * dphi);
  const ts = st / om;
  let dvr = (ts * dPdr) / sig;
  let dvp = (ts * dPdphi) / (sig * r);
  const cs = h / Math.sqrt(r);
  const m = Math.hypot(dvr, dvp);
  if (m > cs) {
    dvr *= cs / m;
    dvp *= cs / m;
  }
  const lnr1 = lnr + ((vr + dvr) / r) * dt;
  let phi1 = phi + ((vp + dvp) / r) * dt;
  phi1 -= TAU * Math.floor(phi1 / TAU);
  g[o] = lnr1;
  g[o + 1] = phi1;
  g[o + 3] = lnr1 < Math.log(R_IN) || lnr1 > Math.log(R_OUT) ? 0 : 1;
}

export function stepGrains(D: Disc, p: DiscParams, g: Float32Array): void {
  for (let o = 0; o < g.length; o += 4) stepGrain(D, p, g, o);
}

/**
 * The analytic radial drift at r for a grain of Stokes number st, from the
 * discrete ring profile: St · (∂P/∂r) / (Σ Ω). Negative in a disc whose
 * pressure falls outward.
 */
export function driftRate(
  D: Disc,
  p: DiscParams,
  r: number,
  st: number
): number {
  const lnr = Math.log(r);
  const rp = Math.exp(lnr + D.dlnr);
  const rm = Math.exp(lnr - D.dlnr);
  const sig = Math.max(sampleGas(D, lnr, 0)[0], D.floor);
  const sp = Math.max(sampleGas(D, lnr + D.dlnr, 0)[0], D.floor);
  const sm = Math.max(sampleGas(D, lnr - D.dlnr, 0)[0], D.floor);
  const dPdr = (cs2(rp, p.h) * sp - cs2(rm, p.h) * sm) / (rp - rm);
  const om = Math.pow(r, -1.5);
  return (st * dPdr) / (sig * om);
}

/**
 * One grain per texel: (ln r, φ, St, alive). Samples the gas bilinearly
 * with φ wrapped by hand, takes the gas velocity plus the terminal-velocity
 * drift t_s ∇P / Σ clamped to c_s, and advances (ln r, φ) — the twin of
 * stepGrain() in grains.ts. A grain past either edge is dead and stays so.
 */
export const GRAIN_STEP_FS = `#version 300 es
    precision highp float;
    precision highp int;
    out vec4 fragColor;
    uniform sampler2D uParticles;
    uniform int uPW;
    ${GRID}
    uniform float uROut, uH, uDt, uFloor;
    const float TAU = 6.28318530718;
    vec4 gas(float lnr, float phi) {
      float fi = (lnr - log(uRIn)) / uDlnr - 0.5;
      float fj = phi / uDphi - 0.5;
      int i0 = int(floor(fi)), j0 = int(floor(fj));
      float ti = fi - float(i0), tj = fj - float(j0);
      vec4 a = mix(S(i0, j0), S(i0, j0 + 1), tj);
      vec4 b = mix(S(i0 + 1, j0), S(i0 + 1, j0 + 1), tj);
      return mix(a, b, ti);
    }
    void main() {
      G = textureSize(uState, 0);
      vec4 g = texelFetch(uParticles, ivec2(gl_FragCoord.xy), 0);
      if (g.w == 0.0) { fragColor = g; return; }
      float lnr = g.x, phi = g.y, st = g.z;
      float r = exp(lnr), om = pow(r, -1.5);
      vec4 c = gas(lnr, phi);
      float sig = max(c.x, uFloor);
      float rp = exp(lnr + uDlnr), rm = exp(lnr - uDlnr);
      float sp = max(gas(lnr + uDlnr, phi).x, uFloor);
      float sm = max(gas(lnr - uDlnr, phi).x, uFloor);
      float dPdr = (uH * uH / rp * sp - uH * uH / rm * sm) / (rp - rm);
      float jp = gas(lnr, phi + uDphi).x, jm = gas(lnr, phi - uDphi).x;
      float dPdphi = uH * uH / r * (jp - jm) / (2.0 * uDphi);
      float ts = st / om;
      vec2 dv = vec2(ts * dPdr / sig, ts * dPdphi / (sig * r));
      float cs = uH / sqrt(r);
      float m = length(dv);
      if (m > cs) dv *= cs / m;
      float lnr1 = lnr + (c.y + dv.x) / r * uDt;
      float phi1 = phi + (c.z + dv.y) / r * uDt;
      phi1 -= TAU * floor(phi1 / TAU);
      float alive = (lnr1 < log(uRIn) || lnr1 > log(uROut)) ? 0.0 : 1.0;
      fragColor = vec4(lnr1, phi1, st, alive);
    }`;

// Run in the tab. Finds the sim context (the one whose canvas is not in
// the document), wraps drawArrays in timer queries, buckets by the bound
// framebuffer and program, and prints ms per frame per bucket.
const P = WebGL2RenderingContext.prototype,
  orig = P.drawArrays;
const stats = new Map();
let frames = 0;
P.drawArrays = function (mode, first, count) {
  if (this.canvas.isConnected) return orig.call(this, mode, first, count);
  const ext = (this.__tq ??= this.getExtension(
    'EXT_disjoint_timer_query_webgl2'
  ));
  if (!ext) return orig.call(this, mode, first, count);
  const q = this.createQuery();
  this.beginQuery(ext.TIME_ELAPSED_EXT, q);
  orig.call(this, mode, first, count);
  this.endQuery(ext.TIME_ELAPSED_EXT);
  const key =
    (this.getParameter(this.FRAMEBUFFER_BINDING) ? 'fbo' : 'canvas') +
    ':' +
    mode +
    ':' +
    count;
  (this.__pending ??= []).push([key, q]);
  if (!this.__tick) {
    this.__tick = true;
    requestAnimationFrame(() => {
      this.__tick = false;
      frames++;
      for (const [k, q] of this.__pending.splice(0)) {
        const done = this.getQueryParameter(q, this.QUERY_RESULT_AVAILABLE);
        if (done) {
          const ns = this.getQueryParameter(q, this.QUERY_RESULT);
          stats.set(k, (stats.get(k) ?? 0) + ns / 1e6);
        }
        this.deleteQuery(q);
      }
    });
  }
};
setTimeout(() => {
  for (const [k, ms] of stats)
    console.log(k, (ms / frames).toFixed(2), 'ms/frame');
}, 10000);
```

Tell them apart by count and by the viewport if the key collides; add `this.getParameter(this.VIEWPORT).join('x')` to the key.
