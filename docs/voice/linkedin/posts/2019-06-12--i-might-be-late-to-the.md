I might be late to the party, but this is exciting:

When I logged into WHM today, I was notified that Node.js 10 was now an installable package for Apache. From the research I've done in the past, it always seemed like Node _could_ be installed, but it required some wizardry that also made it lose some of what makes Node great. Hence, I've had to stick to PHP since I live on the LAMP stack. Sad!

After installing it this morning, however, I couldn't be any happier. The only hiccup I've found was that the "node" command doesn't work immediately (you have to make a .bashrc alias to make it work). Once that's done, it's like butter.
