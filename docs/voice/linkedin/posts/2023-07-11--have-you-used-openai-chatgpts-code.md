Have you used OpenAI
#ChatGPT's code interpreter yet? I just did. 🤯

I'll be honest, I didn't jump on giving it a try when it came out a few days ago because I just thought it would be for Python devs, which I'm totally not. Turns out, it's like having access to a Python dev! 🥳 🐍

In this example, I uploaded a JPEG image and asked ChatGPT to convert it to a PNG file. It took the file, wrote a Python script that handled the conversion, executed the script, and then gave me a link to download the file.

Obviously this is a very rudimentary example of what it can do, but already I'm seeing the potential that it has for devs and non-devs. You'll be able to give it data and look for patterns, parse PDFs for content, scrub websites - really anything.

This is going to be super useful, y'all.
