🚀 If you're a developer and not using AI now, you're already falling behind...

🔧 I've been working on the "skills" section of my portfolio, which includes about 20 different skills. Each skill is supposed to have a label and a logo. But let's be honest, finding logos that you can legally use takes a ton of time.

💡 So, I decided to put AI to work! I used ChatGPT with a web browser plugin to do the heavy lifting for me.

👇 Here's the prompt I gave it:

"Using the browser, I'd like for you to find svg logos for each category that I don't have a logo for already. I should be able to use the svg legally. Then, get me the paths to each SVG. Finally, make sure you follow any licenses that you come across and then create me a page that lists all of the credits for the logos so I can use them."

🎉 And guess what? It worked like a charm!
