## Agent skills

### Issue tracker

Issues live as GitHub issues on `bracketbear/website-monorepo`, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, each mapped to a label of the same name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Lab toys

Candidate toys for the Animation Lab, the rubric they are judged against, and post-mortems of the ones that died. Read the rubric before proposing or specifying a new toy — its first two questions are the ones that cannot be settled by arithmetic, and they are the ones that have killed work here. See `docs/lab/TOY-IDEAS.md`.

An idea graduates out of that file when it gets a spec in `docs/superpowers/specs/`; it comes back with a post-mortem if it is abandoned.
