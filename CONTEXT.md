# Bracket Bear monorepo

Shared vocabulary for this repo. Terms are added when a real ambiguity forces
one of them to be pinned down — this file records what the project has actually
bothered to define, not everything it contains.

## Language

### Writing and voice

**Voice**:
How a piece of writing sounds — rhythm, word choice, punctuation, emoji, the
shape of an opener and a closer. Modeled empirically in `docs/voice/VOICE.md`
from a corpus of real posts.
_Avoid_: "style," "tone" — both get used for register and editorial judgment too.

**Register**:
Which mode a topic selects within a single voice. Harrison's personal writing
has three — casual, measured, serious — and using the wrong one for the topic is
as detectable as using none. Selected by topic, per `VOICE.md` §0.
_Avoid_: "tone," "mood."

**Editorial judgment**:
Whether a piece should exist at all — the positions behind it and whether the
subject is worth posting. Fails independently of voice: a draft can sound
exactly right and still be one Harrison would never publish.
_Avoid_: "content strategy," "editorial voice."

**Brand voice**:
How Bracket Bear speaks as a company, recorded in `docs/brand/BRAND.md`.
Distinct from Harrison's personal voice, and a **decision record** rather than
an empirical model — there was no corpus to derive it from.
_Avoid_: using "voice" alone when the brand is meant.

**Calibration**:
The closed, two-round blind-judge experiment that measured how often judges
could pick AI-written fakes out of a lineup of real posts. It measured
detectability only, never publishability.
_Avoid_: using it loosely for any validation of the profile — output testing is
not calibration.

**Corpus**:
The 202 scraped LinkedIn posts in `docs/voice/linkedin/posts/`. Source material,
never guidance. 192 were analyzed; 10 are the calibration holdout.
